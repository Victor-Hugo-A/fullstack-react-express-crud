# 🚀 Projeto Full-Stack: Express (Node.js) + React

[![Node.js](https://img.shields.io/badge/Node.js-18.x-green)](https://nodejs.org/)
[![Express](https://img.shields.io/badge/Express-4.x-lightgrey)](https://expressjs.com/)
[![React](https://img.shields.io/badge/React-18.x-blue)](https://reactjs.org/)
[![License](https://img.shields.io/badge/License-MIT-yellow)](LICENSE)

Um projeto full-stack moderno com backend em **Express** e frontend em **React**.

## 📌 Visão Geral

- **Backend**: API RESTful com Express (Node.js)
- **Frontend**: Single Page Application (SPA) com React
- **Integração**: Comunicação via JSON entre frontend e backend

## 🛠️ Pré-requisitos

- Node.js 18.x+
- npm 9.x+ ou yarn 1.22+
- Git


## ⚡ Como Executar

### Backend (Express)
```bash
cd server
npm install
npm start
# API estará em http://localhost:5000
```

🌐 Rotas da API (Exemplo)

| Método | Rota |	Descrição |
| -------| ------| ------|
| GET	| /api/users	| Lista todos usuários|
| POST	| /api/users |	Cria novo usuário|
